# ChangeLog

## 0.5.0 (11/06/2026)

### Breaking changes

#### Removed StrawberryShake types

The typed GraphQL client is now generated by the SDK generator instead of StrawberryShake. Every type that `ListingGraphQLClient` accepts or returns keeps its name, namespace (`EBay.ListingManagement.Generated.GraphQL`) and members. The result interfaces, result classes, input classes and enums are unchanged. Only StrawberryShake's own plumbing is no longer public:

- `IListingManagementGraphQLClient`, `ListingManagementGraphQLClient`, and the per-operation `I{Operation}Query`, `I{Operation}Mutation`, `{Operation}Query`, `{Operation}Mutation` and `{Operation}{Kind}Document` types
- `AddListingManagementGraphQLClient` (namespace `Microsoft.Extensions.DependencyInjection`). Use `AddListingManagementSdk`.
- the `EBay.ListingManagement.Generated.GraphQL.State` namespace, `{Enum}Serializer` and `{Input}InputValueFormatter`
- input classes no longer implement `State.I{Input}Info`

#### File downloads return the file

`FeedClient.GetResultFileAsync`, `GetInputFileAsync` and `GetLatestResultFileAsync`, and `MediaClient.DownloadPostOrderDocumentAsync` now return `Task<Stream?>` with the downloaded file. Before, they returned `Task` and the file was discarded. Code that only awaited them compiles unchanged; recompile against 0.5.0.

#### Simpler dependency injection

- `AddListingManagementSdk` now registers only the configuration and a singleton `ListingManagementClient`. `InventoryClient`, `FeedClient`, `MediaClient`, `StoresClient` and `ListingGraphQLClient` are no longer registered individually: inject `ListingManagementClient` and use its `Inventory`, `Feed`, `Media`, `Stores` and `GraphQL` properties.
- The SDK no longer uses `IHttpClientFactory` or registers named `HttpClient`s, and no longer depends on `Microsoft.Extensions.Http`. To customise HTTP (proxy, client certificates, test doubles), use the new `ListingManagementClient(ListingManagementConfiguration, HttpMessageHandler)` constructor.

### Security

- The access token is sent only to trusted hosts. Before, it was attached to requests for any HTTPS host configured as a base URL. The client constructors now throw `InvalidOperationException` when a base URL uses a host that is not trusted.

### Added

- `ListingManagementConfiguration.AllowedHosts` for additional hosts trusted with the access token, and `ListingManagementConfiguration.DefaultAllowedHosts`. The eBay production hosts (`api`, `apim` and `apiz.ebay.com`), their sandbox counterparts (for example `api.sandbox.ebay.com`) and the sandbox GraphQL host `graphqlapi.sandbox.ebay.com` are trusted by default.
- Target framework `net472` (.NET Framework 4.7.2).
- Typed GraphQL operations work with the standalone `new ListingManagementClient(config)` constructor. Before, they needed dependency injection.

### Changed

- Dependency minimums are lowered to the versions Kiota itself requires, so projects can keep older compatible versions: `Microsoft.Kiota.Bundle` >= 1.22.0 and `Microsoft.Extensions.DependencyInjection.Abstractions` >= 6.0.0. Previously the SDK required the newest 10.0.x packages. On .NET Framework the SDK requires `System.Text.Json` >= 10.0.0, matching the oldest supported .NET LTS (.NET 10). None of these minimums has a known vulnerability, and each release is tested at both the minimum and the latest versions.
- `GraphQL.ExecuteRawUnsafeAsync` under dependency injection now throws `UnauthorizedException` for HTTP 401 and `GraphQLException` for other non-2xx responses. It used to throw a raw `HttpRequestException`. Standalone mode already behaved this way.
- On .NET Framework the SDK's HttpClients allow 64 connections per host instead of the `ServicePointManager` default of 2.
- `ListingManagementConfiguration.HttpTimeout` and `RequestOptions.Headers` have `set` accessors instead of `init`, so projects compiled with C# 7.3 can assign them. Existing source compiles unchanged; recompile code that was built against 0.4.0.
- REST documentation links now point to `https://developer.ebay.com` instead of site-relative paths.

### Deprecated

eBay marks the in-store pickup and location-hours fields of the Inventory API as deprecated, so these generated members now carry `[Obsolete]` (compiler warning CS0618 where used):

- `Availability.PickupAtLocationAvailability`, `AvailabilityWithAll.PickupAtLocationAvailability`, `PickupAtLocationAvailability`, `AvailabilityTypeEnum`
- `InventoryLocation`, `InventoryLocationFull` and `InventoryLocationResponse`: `LocationInstructions`, `OperatingHours`, `SpecialHours`; `InventoryLocationResponse.Phone`
- `OperatingHours`, `SpecialHours`, `Interval`

### Fixed

- `MediaClient.CreateImageFromFileAsync` and the other file uploads no longer close the stream you pass in.
- `CreateListingAsync` no longer throws `GraphQLException` ("Value cannot be null.") when the response is a `CreateListingValidationSuccess`.
