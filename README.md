# EBay.ListingManagement .NET SDK

A .NET SDK for eBay seller listing management. Wraps four REST APIs (Kiota-generated) and eBay's GraphQL API (StrawberryShake) behind a single unified client.

## Target framework

`net10.0`

## What's included

| Client | API | Transport |
|---|---|---|
| `Inventory` | Sell Inventory v1 | REST (Kiota) |
| `Feed` | Sell Feed v1 | REST (Kiota) |
| `Media` | Commerce Media v1 beta | REST (Kiota) |
| `Stores` | Sell Stores v1 | REST (Kiota) |
| `GraphQL` | eBay GraphQL | StrawberryShake + dynamic escape hatch |

All five are exposed on `ListingManagementClient` and can also be injected directly via DI.

## Authentication

Tokens are passed per call. Set a global fallback on the config for convenience:

```csharp
var config = new ListingManagementConfiguration
{
    AccessToken = "v^1.1-..."   // fallback when no per-call token is supplied
};
```

Per-call token takes precedence; `AccessToken` is the fallback. If neither is set, the SDK throws at call time.

## Usage

### Without DI (scripts, tests)

```csharp
using EBay.ListingManagement;
using EBay.ListingManagement.Configuration;

var config = new ListingManagementConfiguration { AccessToken = "v^1.1-..." };

using var client = new ListingManagementClient(config);

// REST
var items = await client.Inventory.GetInventoryItemsAsync(limit: 20);
var tasks = await client.Feed.GetTasksAsync();
var store = await client.Stores.GetStoreAsync();

// GraphQL (typed)
var listings = await client.GraphQL.GetSellerListingSearchAsync();
```

### With DI (ASP.NET Core)

```csharp
// Program.cs
builder.Services.AddListingManagementSdk(new ListingManagementConfiguration
{
    AccessToken = builder.Configuration["EBay:AccessToken"]
});
```

Then inject any client directly:

```csharp
app.MapGet("/items", async (InventoryClient client) =>
    Results.Ok(await client.GetInventoryItemsAsync()));

app.MapGet("/store", async (StoresClient client) =>
    Results.Ok(await client.GetStoreAsync()));

app.MapGet("/listings", async (ListingGraphQLClient client) =>
    Results.Ok(await client.GetSellerListingSearchAsync()));
```

### Sandbox

Override base URLs on `ListingManagementConfiguration`:

```csharp
var config = new ListingManagementConfiguration
{
    AccessToken = "...",
    InventoryBaseUrl = "https://api.sandbox.ebay.com/sell/inventory/v1",
    FeedBaseUrl      = "https://api.sandbox.ebay.com/sell/feed/v1",
    MediaBaseUrl     = "https://apim.sandbox.ebay.com/commerce/media/v1_beta",
    StoresBaseUrl    = "https://api.sandbox.ebay.com/sell/stores/v1",
    GraphQLBaseUrl   = "https://api.sandbox.ebay.com/graphql",
};
```

## GraphQL

Typed operations are pre-defined in `graphql/operations/` and code-generated by StrawberryShake at build time.

For anything outside those operations, use the dynamic escape hatch:

```csharp
var doc = await client.GraphQL.ExecuteRawAsync(
    query: "query { sellerListingSearch { listings { itemId title } } }",
    variables: null);

Console.WriteLine(doc.RootElement.GetRawText());
```

## Code generation

Regenerate REST clients from updated OpenAPI specs:

```bash
./generate.sh
```

Regenerate GraphQL client: just `dotnet build` — StrawberryShake's Roslyn source generator runs automatically.

## Sample app

`EBay.ListingManagement.Sample` is an ASP.NET Core Minimal API that exercises every client. It is a smoke test / dog-fooding harness, not a production template.

Run it:

```bash
cd EBay.ListingManagement.Sample

# Option 1: env var
EBAY_ACCESS_TOKEN="v^1.1-..." dotnet run

# Option 2: user-secrets
dotnet user-secrets set "EBay:AccessToken" "v^1.1-..."
dotnet run
```

Then open `http://localhost:5000/swagger` to explore and invoke endpoints for Inventory, Feed, Stores, Media, and GraphQL.
