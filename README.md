# EBay.ListingManagement .NET SDK

A .NET SDK for eBay seller listing management. Wraps four REST APIs (Kiota-generated) and eBay's GraphQL API (typed client generated by the SDK generator) behind a single unified client.

## Target frameworks

`net472` (.NET Framework 4.7.2), `net8.0`, `net9.0` and `net10.0`

## What's included

| Client | API | Transport |
|---|---|---|
| `Inventory` | Sell Inventory v1 | REST (Kiota) |
| `Feed` | Sell Feed v1 | REST (Kiota) |
| `Media` | Commerce Media v1 beta | REST (Kiota) |
| `Stores` | Sell Stores v1 | REST (Kiota) |
| `GraphQL` | eBay GraphQL | Generated typed operations + dynamic escape hatch |

All five are exposed as properties of `ListingManagementClient`.

## Authentication

Tokens are passed per call. Set a global fallback on the config for convenience:

```csharp
var config = new ListingManagementConfiguration
{
    AccessToken = "v^1.1-..."   // fallback when no per-call token is supplied
};
```

Per-call token takes precedence; `AccessToken` is the fallback. If neither is set, the SDK throws at call time.

## Usage

### Without DI (scripts, tests)

```csharp
using EBay.ListingManagement;
using EBay.ListingManagement.Configuration;

var config = new ListingManagementConfiguration { AccessToken = "v^1.1-..." };

using var client = new ListingManagementClient(config);

// REST
var items = await client.Inventory.GetInventoryItemsAsync(limit: "20");
var tasks = await client.Feed.GetTasksAsync();
var store = await client.Stores.GetStoreAsync();

// GraphQL (typed)
var listings = await client.GraphQL.SellerListingSearchAsync(new SellerActiveListingSearchInput());
```

### With DI (ASP.NET Core)

`AddListingManagementSdk` registers the configuration and one shared `ListingManagementClient` (a singleton that owns its HTTP connections and is disposed with the container). Inject the client and use its properties for the individual APIs:

```csharp
// Program.cs
builder.Services.AddListingManagementSdk(new ListingManagementConfiguration
{
    AccessToken = builder.Configuration["EBay:AccessToken"]
});

app.MapGet("/items", async (ListingManagementClient sdk) =>
    Results.Ok(await sdk.Inventory.GetInventoryItemsAsync()));

app.MapGet("/listings", async (ListingManagementClient sdk) =>
    Results.Ok(await sdk.GraphQL.SellerListingSearchAsync(new SellerActiveListingSearchInput())));
```

To route requests through your own handler (proxy, client certificates, a test double), pass it to the constructor: `new ListingManagementClient(config, handler)`. The handler is shared by all APIs and is not disposed by the client.

### Sandbox

Override base URLs on `ListingManagementConfiguration`. The sandbox hosts are trusted with the access token by default:

```csharp
var config = new ListingManagementConfiguration
{
    AccessToken = "...",
    InventoryBaseUrl = "https://api.sandbox.ebay.com/sell/inventory/v1",
    FeedBaseUrl      = "https://api.sandbox.ebay.com/sell/feed/v1",
    MediaBaseUrl     = "https://apim.sandbox.ebay.com/commerce/media/v1_beta",
    StoresBaseUrl    = "https://api.sandbox.ebay.com/sell/stores/v1",
    GraphQLBaseUrl   = "https://graphqlapi.sandbox.ebay.com/graphql",
};
```

### Trusted hosts

The access token is only sent to trusted hosts: the eBay hosts in `ListingManagementConfiguration.DefaultAllowedHosts` (production and sandbox) plus any you add to `AllowedHosts`, for example a proxy:

```csharp
var config = new ListingManagementConfiguration
{
    InventoryBaseUrl = "https://ebay-proxy.example.com/sell/inventory/v1",
    AllowedHosts = { "ebay-proxy.example.com" },
};
```

The client constructor throws `InvalidOperationException` if a base URL uses a host that is not trusted.

## GraphQL

Typed operations and their result, input and enum types are generated by the SDK generator into `EBay.ListingManagement/Clients/GraphQL/Generated/`. At runtime they only use `HttpClient` and `System.Text.Json`.

For anything outside those operations, use the dynamic escape hatch:

```csharp
var doc = await client.GraphQL.ExecuteRawUnsafeAsync(
    "query { sellerListingSearch { activeListings { __typename } } }");

Console.WriteLine(doc.RootElement.GetRawText());
```

## Code generation

Regenerate REST clients from updated OpenAPI specs:

```bash
./generate.sh
```

The GraphQL client is regenerated together with everything else by the SDK generator in `api-sdk-definitions`.

## Sample app

`EBay.ListingManagement.Sample` is an ASP.NET Core Minimal API that exercises every client. It is a smoke test / dog-fooding harness, not a production template.

Run it:

```bash
cd EBay.ListingManagement.Sample

# Option 1: env var
EBAY_ACCESS_TOKEN="v^1.1-..." dotnet run

# Option 2: user-secrets
dotnet user-secrets set "EBay:AccessToken" "v^1.1-..."
dotnet run
```

Then open `http://localhost:5000/swagger` to explore and invoke endpoints for Inventory, Feed, Stores, Media, and GraphQL.

## Dependencies

- **Microsoft.Kiota.Bundle** (>= 1.22.0): REST runtime
- **Microsoft.Extensions.DependencyInjection.Abstractions** (>= 6.0.0): `AddListingManagementSdk` registration
- **System.Text.Json** (>= 10.0.0, .NET Framework only): GraphQL request and response serialization

## Development

- .NET 10 SDK, plus the .NET 8 and .NET 9 SDKs so every target framework can build
- `net472` builds on any OS (reference assemblies come from NuGet); its tests run on Windows only
- Tests: `dotnet test tests/EBay.ListingManagement.Tests`
