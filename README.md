# eBay Listing Management SDK for .NET

Create and manage listings and inventory, upload media, and work with feeds and eBay stores. This SDK wraps the eBay Feed API, Inventory API, Media API, Stores API and eBay GraphQL behind one client, `ListingManagementClient`.

- **Target frameworks:** .NET Framework 4.7.2, .NET 8, .NET 9 and .NET 10
- **C#:** usable from C# 7.3 and later

## Installation

The package `EBay.ListingManagement` is not on nuget.org yet. Reference the project, or build the package and add it to a local feed:

```bash
dotnet pack EBay.ListingManagement -c Release -o artifacts/packages
```

## Quick start

```csharp
using EBay.ListingManagement;
using EBay.ListingManagement.Configuration;

var config = new ListingManagementConfiguration
{
    // A user or application access token from your own OAuth flow (see "Authentication").
    AccessToken = Environment.GetEnvironmentVariable("EBAY_ACCESS_TOKEN")
};

using var client = new ListingManagementClient(config);

var items = await client.Inventory.GetInventoryItemsAsync(limit: "10");
Console.WriteLine($"{items?.Total} inventory items");
```

The GraphQL API is on the same client:

```csharp
using EBay.ListingManagement.Generated.GraphQL;

var result = await client.GraphQL.SellerListingSearchAsync(new SellerActiveListingSearchInput
{
    Pagination = new PaginationInput { MaxPageSize = 10 }
});

// GraphQL unions surface as interfaces: test for the concrete type.
if (result?.ActiveListings is ISellerListingSearch_SellerListingSearch_ActiveListings_SellerListings active)
{
    foreach (var listing in active.Listings ?? [])
    {
        Console.WriteLine(listing.ListingId);
    }
}
```

## GraphQL

`client.GraphQL` has a typed method per GraphQL operation the SDK ships (see the table above). Inputs are classes with settable properties; only the properties you set are sent, so leaving a property unset is different from setting it to `null`. Results are interfaces named after their path in the query, and GraphQL unions surface as one interface per possible type: use `is`/`as` to pick the concrete type, as in the quick start.

For anything else, `ExecuteRawUnsafeAsync` sends any query and returns the response as a `JsonDocument`:

```csharp
using var document = await client.GraphQL.ExecuteRawUnsafeAsync("query { __typename }");
Console.WriteLine(document.RootElement.GetRawText());
```

## Authentication

The SDK does not obtain or refresh tokens: get them with your own OAuth flow ([eBay OAuth guide](https://developer.ebay.com/develop/guides/sell/authorization)) and give them to the SDK in one of two ways:

- `ListingManagementConfiguration.AccessToken`: used for every call that doesn't pass its own token.
- The `accessToken` parameter on every method: used for that call only, for example a user token where the configuration holds an application token.

```csharp
string userToken = Environment.GetEnvironmentVariable("EBAY_USER_TOKEN")!;
var items = await client.Inventory.GetInventoryItemsAsync(limit: "10", accessToken: userToken);
```

A token is only ever sent to trusted hosts, see below.

## Sandbox and trusted hosts

The access token is only sent to trusted hosts: the hosts in `ListingManagementConfiguration.DefaultAllowedHosts`, which are the eBay production hosts and their `*.sandbox.ebay.com` counterparts, plus any in `AllowedHosts`. Switching to the sandbox needs only the base URLs:

```csharp
var sandboxConfig = new ListingManagementConfiguration
{
    AccessToken = Environment.GetEnvironmentVariable("EBAY_SANDBOX_ACCESS_TOKEN"),
    FeedBaseUrl = "https://api.sandbox.ebay.com/sell/feed/v1",
    InventoryBaseUrl = "https://api.sandbox.ebay.com/sell/inventory/v1",
    MediaBaseUrl = "https://apim.sandbox.ebay.com/commerce/media/v1_beta",
    StoresBaseUrl = "https://api.sandbox.ebay.com/sell/stores/v1",
    GraphQLBaseUrl = "https://graphqlapi.sandbox.ebay.com/graphql",
};
```

Any other host, for example a proxy that forwards to eBay, has to be added to `AllowedHosts`; the client constructor throws `InvalidOperationException` otherwise:

```csharp
var proxied = new ListingManagementConfiguration
{
    FeedBaseUrl = "https://ebay-proxy.example.com/sell/feed/v1",
    AllowedHosts = { "ebay-proxy.example.com" },
};
```

## Dependency injection

`AddListingManagementSdk` registers the configuration and one shared `ListingManagementClient` as a singleton. It owns its HTTP connections and is disposed with the container. Inject the client and use its properties for the individual APIs:

```csharp
using EBay.ListingManagement;
using EBay.ListingManagement.Configuration;
using EBay.ListingManagement.Extensions;

var builder = WebApplication.CreateBuilder(args);
builder.Services.AddListingManagementSdk(new ListingManagementConfiguration
{
    AccessToken = builder.Configuration["EBay:AccessToken"]
});

var app = builder.Build();
app.MapGet("/example", async (ListingManagementClient client) =>
{
    var items = await client.Inventory.GetInventoryItemsAsync(limit: "10");
    return Results.Ok();
});
app.Run();
```

## Custom HTTP handler

To send requests through your own handler, for example for a proxy, client certificates or a test double, pass it to the constructor. The handler is shared by all APIs and is not disposed by the client:

```csharp
var handler = new HttpClientHandler { Proxy = new WebProxy("http://corporate-proxy:8080") };
using var proxiedClient = new ListingManagementClient(config, handler);
```

## Error handling

```csharp
try
{
    var items = await client.Inventory.GetInventoryItemsAsync(limit: "10");
}
catch (UnauthorizedException)
{
    // HTTP 401: the token is missing, expired, for the other environment, or lacks a scope.
}
catch (ApiException ex)
{
    // Any other REST error.
    Console.WriteLine($"HTTP {ex.ResponseStatusCode}");
}
catch (GraphQLException ex)
{
    // GraphQL "errors" in the response.
    Console.WriteLine(string.Join("; ", ex.Errors));
}
```

- `UnauthorizedException` (HTTP 401) and `GraphQLException` derive from `SdkException`.
- Other REST errors throw Kiota's `ApiException`, or a generated subclass named in eBay's spec for that operation, with `ResponseStatusCode`. eBay's error text is only available where the spec describes the error body correctly; set `DiagnosticLogging = true` to log failed requests to stderr.

## Development

- .NET 10 SDK, plus the .NET 8 and .NET 9 SDKs so every target framework builds. `net472` builds on any OS; its tests run on Windows only.
- Build: `dotnet build EBay.ListingManagement`
- Test: `dotnet test tests/EBay.ListingManagement.Tests`
- Most of this repository is generated from eBay's API specs by the SDK generator (`api-sdk-definitions`): the API clients, `Configuration/`, `Extensions/`, `ListingManagementClient.cs`, `specs/` and `generate.sh`. Change the generator, not the generated files. `./generate.sh` reruns Kiota for the specs in `specs/openapi`.
